# Sistema Web de Gestión de Pedidos

Aplicación web desarrollada para un negocio gastronómico, orientada a la gestión de pedidos y a la comunicación entre atención y cocina.

## Funcionalidades

- Gestión de pedidos.
- Seguimiento del estado de los pedidos.
- Panel de cocina.
- Comunicación entre frontend y backend mediante API.
- Integración con base de datos.
- Interfaz web adaptada para su uso desde distintos dispositivos.

## Tecnologías

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Supabase
- Git
- GitHub

## Arquitectura

El proyecto cuenta con:

- **Frontend:** interfaz web para la carga y gestión de pedidos.
- **Backend:** servidor desarrollado con Node.js y Express.js.
- **Base de datos:** Supabase.
- **API REST:** comunicación entre las distintas partes de la aplicación.
- **Panel de cocina:** visualización y gestión de los pedidos recibidos.
